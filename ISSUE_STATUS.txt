HOMEFIX - PAGESPEED ISSUE STATUS
================================

Source report: PageSpeed Insights2.pdf, mobile report captured 24 Nov 2026.

1. Improve image delivery (1,090 KiB estimated savings): CODE CHANGES APPLIED.
   Replaced audited hero/cover/bundle images with WebP variants, responsive srcset/sizes,
   and lazy loading for below-the-fold content. Also optimized book samples, certificate,
   AI preview and avatars. Exact new PSI savings still needs a live re-test.

2. Image elements without explicit dimensions: CODE FIX APPLIED.
   All 29 img elements now have width and height; local checks confirm declared aspect ratios
   match the selected source images.

3. Forced reflow (444 ms): CODE FIX APPLIED TO THE IDENTIFIED CAROUSEL PATH.
   Removed offsetLeft/offsetWidth polling and changed active-card tracking to IntersectionObserver.
   A fresh Performance trace is needed to confirm no other source remains.

4. Minify CSS / reduce unused CSS: CODE CHANGES APPLIED.
   Removed selectors with no matches in the supplied current markup, minified CSS, and moved it
   to a hashed stylesheet. Lighthouse re-test needed to confirm audit status.

5. Minify JavaScript / reduce unused JavaScript: FIRST-PARTY CHANGES APPLIED.
   Custom modal and carousel code is minified and deferred in a hashed file. Vendor scripts stay
   because tracking is being preserved; full audit closure is subject to a PSI run.

6. Avoid long main-thread tasks: CODE CHANGES APPLIED; RUNTIME STATUS UNVERIFIED.
   Carousel no longer performs repeated synchronous geometry reads. Meta/Clarity may still run
   main-thread work. Requires a new Lighthouse trace.

7. Contrast: TARGETED COLOR FIXES APPLIED.
   The previously weak orange/gold and muted text colors were darkened. The key adjusted pairs
   exceed WCAG AA 4.5:1 against white/light section backgrounds. Full browser audit still required.

8. Efficient cache lifetimes (206 KiB): PARTLY OUTSIDE SITE CONTROL.
   First-party content-hashed assets now receive one-year immutable caching via vercel.json.
   The report's remaining 206 KiB items are Meta Pixel (20-minute TTL) and Microsoft Clarity
   (1-day TTL). Their response headers are controlled by those vendors. To eliminate those
   specific warnings, the tracking scripts must be removed or replaced. They were preserved.

9. Legacy JavaScript (11 KiB): THIRD-PARTY / NOT FIXED IN THIS BUILD.
   This is from Meta's fbevents.js. The site cannot rewrite the vendor's compiled file. Removing
   Meta Pixel would eliminate this source but also remove its conversion tracking.

10. LCP / TBT: NOT YET VERIFIED.
    Both previous reports returned NO_LCP rather than usable values. This build preloads and
    prioritizes the hero image, but only a new PSI run can confirm whether NO_LCP clears and
    provide meaningful LCP/TBT values. Do not treat these metrics as fixed until then.

11. Other report notes: CLS was 0; Best Practices and SEO were 100; Agentic Browsing was 2/2.
    No changes were needed for those categories in this source report.

IMPORTANT: Static QA passed, but the provided Chromium runtime blocked local navigation with
ERR_BLOCKED_BY_ADMINISTRATOR and the web inspection environment could not access the live URL.
Therefore this package has not been browser-rendered or re-run through PageSpeed after changes.
The PageSpeed-specific statuses above separate source changes from measured confirmation.
